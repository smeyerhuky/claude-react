memberships**, not seven interchangeable city destinations. The new manifest
joins those exact state/place FIPS identities to retained source context, preserving
multiple principal cities in the same CBSA. It selects no anchors or coordinates.

New records retain short literal quotes, factual observations, limitations and
the original HTTP response's hash/length and capture date in UTC. Full HTML,
runtime/form state and the unavailable response body are omitted. These are derived
observations; original-response hashes cannot be recomputed from the summaries.
No gate accepts these records as release evidence.

The checker binds the official principal-city report, requires every exact
city/CBSA membership once, validates canonical prior-city references, new publisher
identities and retained bytes, and rejects duplicate/foreign/missing cities or
cross-city substitutions. A failed HTTP retrieval cannot become publication
evidence, even if the derived-file hash is updated. An entry/adoption claim also
fails. The source classification preserves location, construction, building-entry
and parking-guidance distinctions.
